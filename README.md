# Valuam - Automação para clinicas



Landing page oficial da **Valuam**, empresa focada em automação inteligente para empresas.

O objetivo deste projeto é apresentar a marca, comunicar a proposta de valor da empresa e captar potenciais clientes interessados em soluções de automação e inteligência artificial.

---

## 🚀 Sobre a Valuam

A Valuam desenvolve soluções que automatizam processos e ajudam empresas a economizar tempo, reduzir custos e aumentar resultados.

Nosso primeiro produto está sendo desenvolvido para automatizar processos de cobrança em clínicas odontológicas e de estética, utilizando inteligência artificial e integração com WhatsApp.

## 💻 Executando o projeto

### Clone o repositório

```bash
git clone https://github.com/ValuemTecnologia/valuam-web.git
```

### Entre na pasta

```bash
cd valuam-web
```

### Instale as dependências

```bash
npm install
```

### Execute

```bash
npm run dev
```
